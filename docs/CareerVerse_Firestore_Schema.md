# 🗄️ CareerVerse Firestore Schema

## 1. Users Collection (`users`)

Stores user profile and authentication details.

**Document ID:** `uid` (from Firebase Auth)

```json
{
  "uid": "user_12345",
  "email": "student@example.com",
  "name": "Alex Smith",
  "role": "student",
  "avatarUrl": "https://...",
  "createdAt": "Timestamp",
  "lastLogin": "Timestamp",
  "stats": {
    "totalSimulations": 5,
    "averageScore": 82,
    "topCareer": "Doctor"
  }
}
```

---

## 2. Sessions Collection (`sessions`)

Stores the temporary state of an active simulation.

**Document ID:** `sessionId` (auto-generated)

```json
{
  "sessionId": "sess_abc789",
  "userId": "user_12345",
  "simulationType": "doctor",
  "status": "completed",
  "startTime": "Timestamp",
  "endTime": "Timestamp",
  "transcript": [
    { "role": "npc", "text": "I have chest pain." },
    { "role": "user", "text": "How long have you had it?" }
  ]
}
```

---

## 3. Scores Collection (`scores`)

Stores the final evaluation results generated by the AI.

**Document ID:** `scoreId` (auto-generated)

```json
{
  "scoreId": "sc_999",
  "userId": "user_12345",
  "sessionId": "sess_abc789",
  "simulationType": "doctor",
  "timestamp": "Timestamp",
  "totalScore": 85,
  "skills": {
    "empathy": 90,
    "logic": 80,
    "stress_tolerance": 75,
    "communication": 88
  },
  "feedback": "You showed great empathy but missed the allergy check."
}
```

---

## 4. Careers Collection (`careers`)

Static data defining the available career paths.

**Document ID:** `careerId` (e.g., `career_doctor`)

```json
{
  "careerId": "career_doctor",
  "title": "General Practitioner",
  "description": "Diagnose and treat patients in a clinic.",
  "difficulty": "Hard",
  "duration": "20 mins",
  "skillWeights": {
    "empathy": 0.4,
    "logic": 0.4,
    "stress_tolerance": 0.2
  }
}
```

---

## 5. Logs Collection (`logs`)

System logs for the Admin Dashboard.

**Document ID:** Auto-generated

```json
{
  "type": "simulation_start",
  "userId": "user_12345",
  "message": "Alex started the Doctor Simulation",
  "timestamp": "Timestamp"
}
```
